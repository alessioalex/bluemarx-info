Bluemarx

Bluemarx is a bookmarking application currently under development.

It is designed to let users save, organize, search, and revisit useful links from across the web, including individually selected Reddit posts.

For Reddit content, Bluemarx only accesses posts that a user explicitly chooses to save. It is not intended to crawl subreddits, perform bulk collection, monitor Reddit, vote, comment, submit posts, send messages, or perform moderation actions.

Bluemarx is currently in private development and is not yet publicly available.

Reddit API use

The Reddit Data API will be used to retrieve public content and metadata for individually saved Reddit URLs so they can be represented in a user’s bookmark library.

API requests are user-initiated and limited to explicitly saved URLs. Reddit API data will not be sold or used to train AI or machine-learning models.
